# Бэкенд-платформа онлайн-обучения "LMS-API"

## Описание проекта:
Проект представляет собой специализированный бэкенд-сервер для LMS-системы (Learning Management System), разработанный в рамках концепции SPA (Single Page Application). Сервер функционирует исключительно в режиме REST API, принимая и отдавая строго структурированные JSON-данные. Платформа построена на базе фреймворка Django с использованием инструментария Django Rest Framework (DRF) и СУБД PostgreSQL.

## Реализованная функциональность (Урок 30.1):
1. **Интеграция DRF (Задание 1):** К проекту успешно подключен пакет `djangorestframework`, обеспечивающий сериализацию данных и маршрутизацию эндпоинтов.
2. **Кастомная модель пользователя (Задание 2):** В приложении `users` развернута модель `User` на базе `AbstractBaseUser`. Стандартная авторизация по `username` полностью заменена на уникальный `email`. Добавлены профильные поля: телефон, город и аватарка.
3. **Модели материалов обучения (Задание 2):** В приложении `materials` спроектированы сущности **Курс** (название, превью, описание) и **Урок** (название, описание, превью, ссылка на видео). Между ними реализована связь «один-ко-многим» через `ForeignKey`.
4. **CRUD для Курсов (Задание 3):** С помощью `ModelViewSet` развернут полный автоматический набор API-эндпоинтов для создания, чтения, обновления и удаления курсов.
5. **CRUD для Уроков (Задание 3):** На базе цепочки Generic-классов (`CreateAPIView`, `ListAPIView`, `RetrieveAPIView`, `UpdateAPIView`, `DestroyAPIView`) вручную описаны изолированные эндпоинты для всех операций с уроками.
6. **Редактирование профилей (Дополнительное задание):** Реализован Generic-эндпоинт для обновления персональных данных пользователей системы.

## Стек технологий и окружение:
* **Python** версии 3.13
* **Django** версии 6.0+
* **Django Rest Framework** версии 3.15+
* **PostgreSQL** (основная СУБД)
* **Pillow** (обработка изображений-превью)
* **Пакетный менеджер:** Poetry

## Инструкция по установке и запуску:

1. **Установите все зависимости проекта через Poetry:**
   ```bash
   poetry install
   ```
2. **Настройте файл переменных окружения `.env` в корне проекта:**
   ```env
   SECRET_KEY="ваш_уникальный_секретный_ключ"
   DEBUG=True
   DB_NAME=lms_db
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль_от_postgres
   DB_HOST=127.0.0.1
   DB_PORT=5432
   ```
3. **Убедитесь, что сервер PostgreSQL запущен, и создайте базу данных `lms_db`.**
4. **Сгенерируйте и примените миграции базы данных:**
   ```bash
   poetry run python manage.py makemigrations users materials
   poetry run python manage.py migrate
   ```
5. **Запустите локальный API-сервер:**
   ```bash
   poetry run python manage.py runserver
   ```
6. **Доступные эндпоинты API для проверки в Postman или браузере:**
   * Список курсов: `127.0.0.1:8000/api/courses/`
   * Список уроков: `127.0.0.1:8000/api/lessons/`
   * Создание урока: `127.0.0.1:8000/api/lessons/create/`
   * Обновление профиля: `127.0.0.1:8000/api/users/profile/<id>/update/`
