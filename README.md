# Бэкенд-платформа онлайн-обучения "LMS-API" (Контейнеризация Docker)

## Описание проекта:
Проект представляет собой специализированный REST API бэкенд-сервер для LMS-системы. Вся экосистема приложения полностью контейнеризирована и оркестрирована с помощью Docker и Docker Compose для быстрого развертывания одной командой.

---

## 📋 Инструкция по запуску приложения через Docker Compose

### 1. Подготовка окружения
Убедитесь, что на вашем компьютере запущен **Docker Desktop** (авторизация внутри программы не требуется).

### 2. Настройка конфигурации `.env`
Создайте в корне проекта файл **`.env`** на основе существующего шаблона `.env.template` и заполните параметры:
```env
SECRET_KEY="ваш_секретный_ключ"
DEBUG=True
DB_NAME=lms_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_PORT=5432
```
*Обратите внимание: параметры `DB_HOST`, а также адреса брокера Celery прописывать вручную не нужно, контейнеры связываются автоматически по именам служб внутри сети Docker.*

### 3. Сборка и запуск всех служб единой командой
Выполните в терминале вашего проекта команду оркестрации:
```bash
docker compose up --build
```
Docker Compose автоматически скачает образы, соберет Dockerfile, изолирует базу данных и Redis через директиву `expose`, подключит тома для сохранности данных и запустит в параллели 5 контейнеров: Django-сервер, PostgreSQL, Redis, Celery Worker и Celery Beat.

### 4. Применение миграций внутри запущенного контейнера
После того как контейнеры успешно запустятся, откройте параллельную вкладку терминала и примените миграции к базе данных внутри контейнера командой:
```bash
docker compose exec web python manage.py migrate
```

### 5. Проверка доступности API
Основное приложение будет доступно на вашем компьютере по адресу:
* Интерактивный Swagger UI: http : // localhost : 8000 / api / docs / swagger /
